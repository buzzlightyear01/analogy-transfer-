# Paper workspace instructions

This directory contains the user's ACL paper, derived from their thesis.

The user explicitly authorized pushing every new manuscript version to
https://github.com/buzzlightyear01/analogy-transfer-.git by default.
After completing a paper revision, compile and inspect the resulting PDF,
update acl_latex.pdf, commit the manuscript changes, and push the commit to
the configured GitHub remote without asking for confirmation again.
Respect tool-level sandbox approval requirements. Never force-push or discard
remote changes. Pull and reconcile remote changes when required.
Only commit paper assets and relevant documentation; exclude build caches,
credentials, raw unrelated thesis data, and temporary files.
Use the official ACL style without modifying acl.sty or shrinking its margins
or fonts. Keep the main paper within eight pages; limitations, references,
and appendices may follow. Preserve numerical provenance and distinguish
oracle-assisted continuation from independent model performance.
